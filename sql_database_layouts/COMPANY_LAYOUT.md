# ContactBook Database Layout: 

This document describes the columns, types, and possible values for a ContactBook
SQL database.

---

## Company SQL Database Layout

| Column Name      | Type                | Example Values / Notes                                                                 |
|------------------|---------------------|----------------------------------------------------------------------------------------|
| **company_id**   | int PRIMARY KEY     | 1
| **company_name** | VARCHAR(70)         | Example Corp                                                          
| **street**       | VARCHAR(50)         | 456 Remington Lane                           
| **city**         | VARCHAR(50)         | Jacksonville
| **state**        | VARCHAR(10)         | FL
| **zip**          | VARCHAR(10)         | 69874
